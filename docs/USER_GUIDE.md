# Руководство пользователя Personal OS

Это локальная персональная система для задач, учёта времени и анализа работы. Данные задач и времени хранятся в backend/PostgreSQL; выбранная тема оформления хранится в браузере.

## Запуск на Windows

1. Запусти Docker Desktop и дождись статуса **Running**.
2. Открой PowerShell в папке репозитория.
3. Убедись, что файл `.env` создан из `.env.example` и содержит локальные секреты. Не отправляй этот файл в GitHub и не пересылай его содержимое в чат.
4. Запусти сервис:

   ```powershell
   docker compose up --build
   ```

5. Открой Web: http://localhost:5173. API и Swagger доступны по http://localhost:8000 и http://localhost:8000/docs.
6. Для остановки нажми Ctrl+C в терминале, затем при необходимости выполни `docker compose down`. Не используй `docker compose down -v`, если хочешь сохранить базу данных.

## Основные разделы

- **Обзор дня** — быстрый взгляд на текущие задачи и рабочее пространство.
- **Планировщик** — список активных задач с приоритетами. Пока это не полноценный календарный вид.
- **Задачи** — добавляй задачу, указывай направление, приоритет и примерную длительность. Отмечай выполненные задачи и фильтруй список.
- **Фокус и время** — запускай таймер для учёта фактической работы. Для прошедшей работы можно добавить запись вручную. Проверяй начало, окончание, категорию и привязку к задаче.
- **Аналитика** — смотри записанное время по дням и категориям. Таймер/ручная запись отражают факт; оценка задачи — только план.
- **Учёба** — сейчас рабочее представление задач учебного направления. Создавай задачи с категорией «ITMO / Учёба» или с ключевыми словами «лабораторная», «контрольная», «домашнее задание». Отдельные карточки предметов и академические сущности требуют backend-модуля.
- **ML и проекты** — задачи, связанные с проектами и разработкой.
- **Репетиторство** — задачи подготовки и проведения занятий. Полноценная CRM учеников, начислений и оплат — отдельный модуль.
- **Финансы** — пока не является полноценным учётом личного бюджета в этой ветке. Не используй задачи как замену финансовым операциям.
- **Настройки** — выбор светлой или тёмной темы. Тема сохраняется в текущем браузере и не синхронизируется между устройствами.

## Рекомендованный ежедневный сценарий

1. Утром добавь задачи и выставь приоритеты и оценки длительности.
2. Распредели задачи по категориям, чтобы видеть учебные, проектные и репетиторские направления.
3. Во время работы запускай таймер; после завершения останови его, чтобы сессия сохранилась как фактическое время.
4. Если забыл включить таймер, добавь ручную запись с корректным интервалом.
5. В конце дня открой аналитику и сравни план с фактом. Не делай выводы о продуктивности только по часам: учитывай реальные результаты.

## Google Calendar и интеграции

Для Google Calendar необходим OAuth-клиент в Google Cloud Console и настройки redirect URI, согласованные с backend. Client Secret и токены должны храниться только в локальном `.env`/backend; никогда не коммить их и не вставляй в публичные сообщения. До успешного OAuth-подключения события календаря не считаются подключёнными.

## Важные ограничения

Эта версия предназначена для локальной разработки. Перед хранением чувствительных данных или использованием в production нужны проверка CI, проверка OAuth в реальном аккаунте, резервное копирование и тест восстановления базы. Не храни в задачах пароли, платёжные реквизиты и другие секреты.
